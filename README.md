# huffman-archiver

CLI архиватор на базе алгоритма Хаффмана.

---

### Статус проекта

Основные функциональности архиватора (сжатие и распаковка) полностью готовы и протестированы. 
Текущая работа сфокусирована на проведении экспериментов для оценки производительности.

**Важно**: Все актуальные изменения находятся в ветке [`work`](https://github.com/AndyBarnv/huffman-archiver/tree/work).

### Сборка

Для компиляции проекта в бинарный файл (выполните из корня репозитория):
```bash
go build -o huff ./cmd/huff
```

---

### Использование

Программа поддерживает два режима работы: сжатие и распаковка.

**Сжатие файла:**
```bash
./huff -c input.txt archive.huff
```

**Распаковка файла:**
```bash
./huff -d archive.huff output.txt
```
